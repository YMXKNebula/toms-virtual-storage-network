# 1.0.0 验证范围

正式构建执行了 28 项核心测试与 55 项服务器测试，全部通过。测试覆盖线路与查询失效、双箱、终端计数、虚拟仓库容量、事务、拆桶转存和连接器入口。

与曲率漏斗 1.0.0 的组合验证另有三组各 18 项测试：正常堆叠、128/32/1、256/48/4。包括连续少量补货、源耗尽再补货、远端连接器实际卸载/重载、漏斗所在区块实际卸载/重载。全部通过。

本次将已登记但暂时卸载的连接器纳入原有待就绪端点检查。连接器恢复加载后，旧的空入口缓存能够自行更新；无需拆除重放漏斗，不强制加载区块。

测试均使用独立世界，不使用或发布玩家整合包、存档及配置。报告中的“通过”仅指列出的测试范围，不代表所有第三方存储接口、真实多客户端网络或全部异常退出窗口均已覆盖。

历史开发版曾进行三维度共 30 万木桶与 12 名假人测试；1.0.0 没有重跑该规模，不将旧 TPS 数值作为本版性能保证。磁盘分页与跨维度虚拟仓储尚未实现。

正式安装包与测试编译结果逐类核对，源码包逐文件核对。校验信息见 [verification.json](test-results/1.0.0/verification.json)，下载文件哈希另见 Release 的 `SHA256SUMS.txt`。

独立客户端还验证了真实终端界面的数量、取出与重新存入，以及木桶激活状态和材质；曲率漏斗截图由该客户端实际拍摄。测试进程使用了专用 JVM 参数，不能据此认定其他环境的客户端异常退出已经解决。
